Кошелёк Сбера vs кошелёк Самоката

Город: Москва. Полный кошелёк клиента Сбера (структура gmv), кошелёк аудитории Самоката в Сбере (smkt_gmv), структура сценариев по мега и ml1, недоборы и NEW-эталон.

  1. Кошелёк Сбера целиком Доли доменов по gmv клиентов в срезе prefs.
  2. Кошелёк Самоката Мега-миссии и ml1 из scenario GMV (агрегат, не user-level).
  3. Сравнение / gap Полный Сбер − аллокация сценариев через soft-bridge.
  4. Эталон Specialty / фуд ml1; аудит миссий без эталона или с пустым составом.

Топ-3 недобора · Москва

  1. Маркетплейсы — недобор +29,5 п,п, (Сбер целиком 29,6% · аудитория СМКТ 31,2% vs сценарии 0,2%). Канал (маркетплейсы) силён в Сбере, слабо в сценариях — не эталон, а ось Where.
  2. Бытовая техника и электроника — недобор +4,2 п,п, (Сбер целиком 4,7% · аудитория СМКТ 4,6% vs сценарии 0,5%). Недобор 4.2 п.п.; NEW-эталон уже широкий (436 SKU) → причина не в узком эталоне (миссии / спрос / канал).
  3. Аптеки — недобор +3,4 п,п, (Сбер целиком 5,3% · аудитория СМКТ 4,3% vs сценарии 1,9%). Недобор 3.4 п.п.; NEW-эталон уже широкий (293 SKU) → причина не в узком эталоне (миссии / спрос / канал).

Как читать

  • Два кошелька Сбера: gmv (целиком) и smkt_gmv (аудитория Самоката).
  • Pie: Сбер = MCC, Самокат = имена сценариев; hover через scenario_mcc_bridge.
  • Gap = полный Сбер − сценарии→MCC. Soft bridge не user-level.
  • ml1 — второй разрез Самоката; grocery MCC = NEW food-lvl1 rollup (FOODZOO/FMCG минус specialty).
  • Узкий эталон: NEW (МАКС+15) < 50 SKU.
