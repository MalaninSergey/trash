# Отчёт: аналоги ФОСФОТЕХ-А3 на китайском рынке

## 1. Идентификация исходного продукта

| Параметр | Значение |
|---|---|
| Наименование | **ФОСФОТЕХ®-А3** |
| Производитель | ООО «ТЗК Экохиммаш» (www.ecochim.ru) |
| Тип | Концентрат обезжиривающе-фосфатирующий (cleaner-coater) |
| Класс технологии | **Железофосфатирование / аморфное фосфатирование** (iron phosphating, Fe-ph) |
| Китайские названия аналогов | 铁系磷化液 / 非晶态磷化液 / 脱脂磷化二合一 / 喷淋磷化液 |

### Назначение
Одновременное **обезжиривание + аморфное фосфатирование** стали и цветных металлов (алюминий, горячеоцинкованная и электрооцинкованная сталь) методом **распыления (струйный тоннель)** или окунания **перед окрашиванием**, в т.ч. порошковым.

Формирует аморфное железофосфатное покрытие массой **0,2–1,0 г/м²** для адгезии ЛКП; низкое шламообразование; **без Zn / Ni / Mn**.

### Состав (по данным из документов)
- Ортофосфорная кислота ≤15% (CAS 7664-38-2)
- Фосфаты металла ≤30%
- Модифицирующая добавка ≤0,5%
- Вода — остальное

### Ключевые рабочие параметры

| Параметр | Требование заказчика (Форма 1.2) | TDS ФОСФОТЕХ-А3 (распыление) |
|---|---|---|
| Метод | Струйный / распыление, проходной тоннель | Распыление / окунание |
| Концентрация | 10–20 г/л | 18–25 г/дм³ |
| Время | 2–4 мин | 2,0–3,5 мин |
| Температура | ≤50 °C | 45–60 °C |
| Общая кислотность | 4–6,5 точки | — |
| pH | 5,0–5,5 | — |
| Упаковка | ПЭ бочка ≤70 л | 65 л / 75 кг |

### Типовой процесс
`Обезжиривание+фосфатирование (струйный тоннель) → контроль смачиваемости (плёнка без разрывов) → промывка → сушка → окраска/порошок`

## 2. Критерии поиска аналогов

Искали продукты, которые одновременно:
1. Являются **кислотным однокомпонентным концентратом** на фосфатах
2. Работают как **cleaner-coater** (обезжиривание + фосфатирование в одной ванне)
3. Дают **аморфную железофосфатную плёнку** ~0,2–1,0 г/м²
4. Пригодны для **spray tunnel** перед порошковой окраской
5. Предпочтительно **без тяжёлых металлов Zn/Ni/Mn** (или с минимальным содержанием)
6. Рабочий диапазон: ~10–25 г/л, ~40–60 °C, 1,5–4 мин, pH ~4,5–6

**Не путать с:**
- цинковым / марганцевым фосфатированием (锌系 / 锰系) — другая плёнка, больше шлама;
- «четырёхв-одном» (四合一: масло+ржавчина+фосфат+пассивация) для ручной обработки ржавых деталей — часто другой pH/кислотность и не оптимальны для промышленного spray-тоннеля;
- фосфатированием для волочения проволоки (wire drawing) — другая задача и другая масса плёнки.

## 6. Рекомендации по закупке / RFQ

При запросе у китайских поставщиков указывайте (можно копировать):

```
Product: Iron phosphating / amorphous phosphate cleaner-coater concentrate
Application: spray tunnel pretreatment before powder coating
Substrates: CRS steel, HDG, electro-galvanized, aluminum (mixed line preferred)
Working bath: 10–20 g/L, ≤50 °C, 2–4 min, pH 5.0–5.5, total acidity 4–6.5 points
Coating weight: 0.2–1.0 g/m² amorphous iron phosphate
Requirements: low foam for spray, low sludge, no Zn/Ni/Mn preferred
Packaging: PE drum ≤70 L
Need: TDS, SDS, sample 2 L + trial batch ~400 L, price FOB/CIF
```

### Приоритет контактов
1. **Qingdao Love Beings / ICON** — профильный экспорт фосфатирующих жидкостей  
2. **Baoding Lanpa** — iron phosphate liquid под порошок  
3. **Chemzip / Winsir** — экспортные карточки с близкими TDS  
4. **Дистрибьюторы BONDERITE M-FE** в КНР — если нужна гарантированная воспроизводимость процесса  
5. Массовый скрининг через **Alibaba + 1688** по ключам выше с запросом TDS до оплаты

### На что смотреть в TDS перед заказом
- Есть ли **встроенный surfactant** (иначе нужен отдельный degreaser additive)
- **Пенообразование** при 1–2 bar spray
- Рабочий **pH 4,5–6** (не 1–2 как у многих 四合一)
- Масса плёнки **0,2–1,0 г/м²**, а не 5–15 г/м² (это уже Zn/Mn)
- Заявление **без тяжёлых металлов** / RoHS / REACH при необходимости экспорта
